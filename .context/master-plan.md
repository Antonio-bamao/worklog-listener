# Work Activity Tracker 总体计划

## 目标

- 在 Windows 10/11 上提供个人自用的本地工作活动记录器。
- 通过 `pythonw.exe` 静默运行 Python 脚本，不打包 exe，不联网，不上传数据。
- 按天输出 Markdown 原始日志到 `%LOCALAPPDATA%\WorkLog\raw\YYYY-MM-DD.md`。
- 记录应用窗口、浏览器 URL、键盘活跃聚合、常用热键、剪贴板、粘贴关联、AFK 空闲和恢复事件。
- 主动跳过密码框内容；不做截图、OCR、鼠标轨迹、网络抓包或中文逐字还原。

## 阶段与里程碑

### Phase 1 - v0.1 单文件可运行版

- 产出 `tracker.py`，直接用 Python 运行。
- 实现单实例锁、日志落盘、窗口轮询、浏览器 URL 读取、键盘聚合、剪贴板轮询、空闲检测。
- 提供基础周归档函数或命令入口，生成可读周摘要。
- 为纯逻辑部分提供自动化测试，Windows API 相关逻辑保持可降级。

### Phase 2 - 自用验证

- 按文档配置 Defender 白名单和任务计划程序。
- 连续自用 1-2 周，观察日志可读性、性能、误报和隐私边界。
- 根据真实日志迭代字段、聚合粒度、归档质量。

### Phase 3 - 开源准备

- 完善 README、配置说明、安装脚本、验收清单。
- 补充更多测试与故障排查文档。
- 评估是否需要拆分模块或保留单文件发布。

## 验收标准

- `tracker.py --once` 能在当前机器上启动一次采集循环并写入当天日志。
- 日志格式符合 `时间戳  [事件类型]  内容`。
- 密码框检测命中时只写 `[SKIP_PWD]`，不记录内容。
- 没有网络请求和远程输出路径。
- 自动化测试覆盖日志格式、路径生成、键盘聚合、剪贴板摘要、周归档等纯逻辑。
