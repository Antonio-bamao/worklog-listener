# 风险台账

| 风险 | 触发条件 | 影响 | 缓解策略 |
| --- | --- | --- | --- |
| Windows API 依赖缺失 | 未安装 `pynput`、`pywin32`、`uiautomation`、`psutil` | 监听功能无法启动 | 启动时检查依赖并提示安装命令 |
| UIA 无法读取部分控件 | 浏览器或应用控件不可访问 | URL、密码框、自动填充准确率下降 | 失败时跳过内容，只保留窗口事件 |
| 剪贴板包含敏感信息 | 用户复制密钥、客户资料等文本 | 本地日志敏感度升高 | 仅本地落盘，最大长度截断，密码框跳过 |
| 后台进程异常退出 | 系统休眠、依赖异常、Hook 中断 | 记录中断 | 捕获异常写日志，配合任务计划程序失败重试 |
